# 首次安装命令（在 Ubuntu SSH 中执行）

```bash
sudo apt update
sudo apt install -y python3-venv python3-pip rsync ufw curl debian-keyring debian-archive-keyring apt-transport-https
sudo useradd --system --home /opt/super-agent --shell /usr/sbin/nologin superagent || true
sudo mkdir -p /opt/super-agent /etc/super-agent
sudo chown -R superagent:superagent /opt/super-agent
cd /opt/super-agent
python3 -m venv .venv
. .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

将 `super-agent-api.service`、`super-agent-scheduler.service` 复制到 `/etc/systemd/system/`，将环境文件复制到 `/etc/super-agent/super-agent.env` 并执行 `chmod 600`。先生成随机回调路径，再将 `Caddyfile.example` 中的 `CALLBACK_PATH` 换成该值后放到 `/etc/caddy/Caddyfile`：

```bash
openssl rand -hex 24
```

最终 UUMit 回调地址为 `https://superquant-2026.duckdns.org/<随机路径>`，Caddy 会将该路径重写到内部 `/analyze`。

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now super-agent-api super-agent-scheduler
sudo systemctl enable --now caddy
sudo ufw allow OpenSSH
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw --force enable
curl -fsS http://127.0.0.1:8000/health
curl -fsS https://superquant-2026.duckdns.org/health
```

DuckDNS 更新（把 token 放在服务器 root 受限文件中，不要提交）：

```bash
curl "https://www.duckdns.org/update?domains=superquant-2026&token=$DUCKDNS_TOKEN&ip=134.175.19.111"
```

查看状态：`systemctl status super-agent-api super-agent-scheduler caddy`；查看日志：`journalctl -u super-agent-api -u super-agent-scheduler -f`。
